## 02 / 自己做的小工具

每一个都始于一件每天都在烦我的小事，最后变成我自己每天在用的东西。都可以免费下载。

| 产品 | 做什么 | 平台 · 技术 | 从这里开始 |
| :--- | :--- | :--- | :--- |
| **ZTABLE** | 把凌乱的 Windows 桌面收进可折叠的「围栏」，自动归类，纯本地运行不联网 | Windows 10/11 · Electron | [源码](https://github.com/AuyeungZEKI/ZTABLE) · [介绍](https://zengqi-zeki.top/products) |
| **Mopad** | 让 Magic Mouse 也拥有触控板手势：轻点、右键、捏合缩放，带防误触规则 | macOS 14+ · Swift / SwiftUI | [官网](https://mopadwebsite.vercel.app) · [介绍](https://zengqi-zeki.top/products) |
